Code Delivery - EXAM 01
This repository contains the implementations for Exam 01 of the CI Expert (Polo UFCG) training program. The project focuses on environment automation via Shell Script and Digital Design Verification (EDA).

📂 Repository Organization
The repository is structured as follows:

scripts/: Contains the developed automation scripts.

gen-prj.sh: Script for automatic generation of new project directory structures.

hello.sh: Basic environment test script.

prj/hello/: Example project generated by the script, containing the following subfolders:

rtl/: Source code for the Design Under Test (DUT - dut.sv / calc4.sv).

tb/: Testbenches and verification files (calc4_tb.sv, tb_top.sv).

docs/: Project documentation, including this README.md.

🚀 How to Run
1. Project Automation (gen-prj.sh)
To create a new project with the default structure, use the following commands:

Bash
chmod +x scripts/gen-prj.sh
./scripts/gen-prj.sh <project_name>
Functionality: The script checks if a name was provided and if the directory already exists. If not, it creates the rtl, tb, and docs folders with .empty files for version control.

2. Design Verification (EDA)
To simulate the calc4 module:

Navigate to the project folder.

Use your EDA simulation tool (e.g., ModelSim/Questa) to compile the files in rtl/ and tb/.

Run the simulation for the calc4_tb.sv Testbench.

📤 Expected Output
gen-prj.sh Script: Displays the message "Project '<name>' successfully created inside prj/" upon successful creation. If the argument is missing, it displays a usage error.

calc4 Simulation: The Testbench processes arithmetic operations (addition, subtraction, multiplication, and division) based on the op signal and generates the corresponding waveforms for analysis in a Waveform Viewer.

📝 Notes for Grading
The calc4 module was implemented using combinational logic (always_comb).

Version control was organized using branches as requested in the EDA exercise.
